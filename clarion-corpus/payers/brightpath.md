# BrightPath

Regional New England payer with the most mature API program among the regionals — real FHIR R4 claims submission and status, "not a portal scrape" per [[people/vik-malhotra]]. Q3 pilot decided 2026-05-06, limited to [[clients/summit-behavioral-health]], live 2026-08-01. Through Aug 12: 312 claims, 97.1% auto-adjudicated, median status latency ~4s (vs ~11 days on paper).
